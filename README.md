# Rust Stacks 3.0 (Minecraft 1.12.2 Forge)

Стаки как в Rust для ванильных предметов и предметов MineRust Addons.
Настройки: `config/ruststacks.cfg` (создаётся при первом запуске).

## Что исправлено
- **Креатив**: ванильный сервер удалял стаки больше 64 при любом клике в инвентаре — теперь нет.
- Количество в стаке хранится как int: в сохранениях (NBT) и в сетевых пакетах — стаки 100/500/1000 не обнуляются при открытии инвентаря или сундука.
- Сундуки, инвентарь, ящики/шкафы MineRust принимают большие стаки (лимит слота = максимальный размер из конфига).
- Сервер отправляет игрокам свои размеры стаков, поэтому у всех одинаково.
- Новый modid `ruststacks` — больше нет конфликта с `stack500`.

## Сборка через GitHub
1. Создай репозиторий и залей туда всё содержимое архива (вместе со скрытой папкой `.github`).
2. Вкладка **Actions** → workflow **Build** (запустится сам или через *Run workflow*).
3. После зелёной галочки скачай артефакт **ruststacks-1.12.2** внизу страницы.
4. В `mods` клади `ruststacks-1.12.2-3.0.jar` (не `-dev` и не `-sources`).

## Установка
- Удали из `mods` старые `ruststacks-1.12.2-2.0.jar` и `stack500-1.12.2-1.0.jar`.
- На сервере мод нужен и на сервере, и у всех игроков.
- Старый `config/ruststacks.cfg` подходит (формат тот же). Чтобы получить новые значения по умолчанию — удали его.
- Предметы, у которых уже было больше 127 и которые «пропали» со старой версией, не вернутся — проверяй на новых.
